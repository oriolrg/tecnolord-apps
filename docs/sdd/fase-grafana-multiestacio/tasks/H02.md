# H02 — Mapping Grafana ↔ catàleg ↔ PDF

## Objectiu

Construir l'inventari canònic de les 29 estacions actuals descobertes a H01.

Per cada sensor, determinar només amb evidència:

- external_id
- nom canònic
- codi MLW, si està documentat
- estat de correspondència
- fonts/evidència
- discrepàncies pendents

No modificar BD.

## Inputs

- `STATE.md`
- `evidence/H01-grafana-sensors.json`
- catàleg conegut de H01
- `Estacions - llista(2).pdf`

## Regla de fonts

Per noms:
1. catàleg conegut actual proporcionat per l'usuari;
2. PDF com a font auxiliar.

Per codi MLW:
- utilitzar el PDF quan la correspondència és explícita.

No substituir silenciosament un nom del catàleg per un nom diferent del PDF.

Si hi ha divergència:
`PENDENT_REVISIO`

## Casos especials

### Identificadors truncats

Conservar exactament:

- `Meteo-026-` → Cal Sec
- `Meteo-027-` → Coll de Port
- `Meteo-029-` → Casa Postils

No completar cap sufix.

Poden tenir codi MLW si el PDF ho acredita, però el binding continua considerant-se parcial.

### Grafana-only

- `S31-119416`
- `S31-99933`

No inferir nom, MLW ni correspondència.

Classificació:
`UNIDENTIFIED_GRAFANA`

### Sensors històrics

Els 7 sensors que H01 només ha trobat fora de la finestra actual de 24 h:

- EM300th-301004
- EM300th-511008
- Meteo-006-3100492
- Meteo-014-3300344
- S31-119412
- S31-99925
- S31-99926

No formen part de les 29 estacions actives d'aquest inventari.

Guardar-los en una secció separada:
`HISTORICAL_NOT_CURRENT`

No importar-los ni intentar geolocalitzar-los en aquesta fase.

## Sortida versionable

Crear:

`evidence/H02-station-mapping.json`

Per cada sensor actual:

{
  "external_id": "...",
  "name": "...",
  "mlw_code": "...",
  "grafana_status": "CURRENT",
  "mapping_status": "...",
  "sources": [...],
  "notes": null
}

Estats permesos:

- CONFIRMED
- PARTIAL_EXTERNAL_ID
- UNIDENTIFIED_GRAFANA
- PENDENT_REVISIO

No inventar `mlw_code`.

## Taula final

external_id | mlw_code | name | mapping_status | notes

## Validacions

- exactament 29 sensors actuals;
- cap external_id inventat;
- cap sensor duplicat;
- tots els MATCH de H01 representats;
- els 3 parcials continuen parcials;
- els 2 S31 continuen sense identitat si no hi ha evidència;
- sensors històrics separats dels actuals.

## Prohibit

- Google Maps;
- coordenades;
- BD;
- importació;
- backend/frontend;
- discovery de mètriques;
- humitat/pressió/pluja;
- avançar H03.

## PASS

H02 PASS si els 29 sensors actuals tenen una classificació explícita i
tota dada de nom/MLW té una font identificable.

Actualitzar STATE.md al final només amb resultats verificats.
