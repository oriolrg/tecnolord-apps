# H09B — Diagnòstic i correcció de la capa topogràfica

## Objectiu

Diagnosticar i corregir la incidència per la qual la capa/base
topogràfica del mapa MeteoLord no es mostra correctament.

Treballar sobre la baseline H09A PASS.

La tasca ha de començar per diagnòstic.

NO modificar a cegues.
NO tocar producció.
NO avançar H10 fins que el mapa estigui verificat.

---

## Baseline

Utilitza:

- `STATE.md`
- evidència H08
- evidència H09A

No repetir H01-H09A.

Estat funcional actual:

- 29 estacions Grafana
- 10 ubicacions HIGH
- selector funcional
- mapa administratiu mostra els punts
- capa topogràfica/base no es visualitza correctament
- frontend no consulta Grafana directament

---

# 1. PRIMER DIAGNÒSTIC

Abans de modificar codi, reproduir la incidència amb navegador real.

Registrar:

- URL carregada;
- errors de consola;
- requests de xarxa relacionats amb el mapa;
- HTTP status;
- MIME/content-type quan sigui rellevant;
- sources i layers carregats;
- style actiu;
- zoom;
- visibilitat;
- errors MapLibre/PMTiles/worker.

No modificar res abans de tenir una hipòtesi sustentada.

---

# 2. IDENTIFICAR ARQUITECTURA ACTUAL DEL MAPA

Localitzar el codi actual i determinar:

- llibreria de mapa utilitzada;
- style URL o style object;
- sources;
- layers;
- PMTiles, vector tiles o raster;
- sprites;
- glyphs;
- worker;
- assets locals;
- paths same-origin;
- Caddy/path prefix relacionat amb `/meteo/`.

No refactoritzar.

---

# 3. BASE TOPOGRÀFICA ESPERADA

Determinar quina source/layer constitueix realment la capa topogràfica.

No assumir-ne una de nova.

Comprovar si el projecte ja conté:

- style topogràfic;
- PMTiles;
- tileset vectorial;
- raster tiles;
- sprites;
- glyphs;
- configuració associada.

Utilitzar els assets ja previstos pel projecte.

No substituir la capa per OpenStreetMap o un altre proveïdor només
per fer desaparèixer l'error, tret que el disseny existent ja ho contempli.

---

# 4. PATHS I SAME-ORIGIN

Comprovar especialment els paths sota:

`/meteo/map-assets/`

i qualsevol prefix equivalent existent.

Verificar:

- path al navegador;
- path dins Docker;
- path servit per Caddy;
- path referenciat al style;
- assets relatius;
- PMTiles URL;
- sprites/glyphs.

La incidència pot ser un problema de path i no del mapa.

No canviar URLs sense provar-les.

---

# 5. PMTILES / TILES

Si s'utilitza PMTiles:

comprovar:

- fitxer existeix;
- és accessible;
- Range requests funcionen;
- status esperats;
- mida no zero;
- MIME acceptable;
- protocol PMTiles registrat;
- source URL correcta.

Si no és PMTiles, documentar el mecanisme real i validar-lo equivalentment.

---

# 6. STYLE

Comprovar:

- style carrega sense error;
- source IDs referenciats existeixen;
- layer IDs existeixen;
- `source-layer` correcte;
- minzoom/maxzoom;
- visibility;
- opacity;
- filtres;
- ordre de layers.

Una capa existent però transparent/fora de zoom també és defecte.

---

# 7. SPRITES I GLYPHS

Si el style els necessita:

comprovar que:

- sprite JSON/PNG existeixen;
- glyph endpoint/path és accessible;
- no hi ha 404;
- no hi ha problema CORS;
- no hi ha path absolut incorrecte.

No afegir dependències externes innecessàries.

---

# 8. WORKER

Si MapLibre/PMTiles utilitza worker:

comprovar:

- worker carregat;
- CSP;
- MIME;
- bundling;
- path;
- errors de consola.

Només modificar si és causa demostrada.

---

# 9. CADDY

Si el problema és de serving:

comprovar configuració local de Caddy:

- `/meteo/`
- `/meteo/map-assets/`
- headers Range
- content types
- fallback SPA

Evitar que el fallback HTML intercepti assets del mapa.

No tocar configuració de producció.

---

# 10. CORRECCIÓ

Després del diagnòstic:

aplicar el canvi mínim que resolgui la causa.

No redissenyar el mapa.

No canviar:

- estacions;
- coordenades;
- permisos;
- dades meteorològiques;
- API;
- Grafana;
- visibilitat pública.

---

# 11. MAPA ADMIN

Després de la correcció comprovar:

- base topogràfica visible;
- 10 punts HIGH visibles;
- zoom/pan funcionals;
- markers/layers per sobre de la base;
- cap coordenada modificada;
- cap estació addicional inventada.

---

# 12. MAPA PÚBLIC

Comprovar que la correcció de la base no altera permisos.

Esperat:

- base map pot carregar;
- estacions ADMIN/PRIVATE Grafana: 0 visibles públicament.

---

# 13. NETWORK

Amb navegador real:

no hi ha d'haver:

- 404 dels assets requerits;
- 500;
- errors CORS;
- peticions directes a Grafana.

Registrar requests de mapa rellevants.

- same-origin;
- source/layer config;

- browser smoke.

No crear tests artificials aliens al defecte.

Suite completa després de la correcció.
