## Objectiu

Obtenir una primera ubicació geogràfica contrastada per les estacions
actuals identificades a H02.

La ubicació s'ha de buscar principalment a Google Maps utilitzant
el nom canònic de H02.

Aquesta tasca només genera inventari/evidència.

## Context geogràfic obligatori

Prioritza coincidències compatibles amb:

- Sant Llorenç de Morunys
- Guixers
- La Coma i la Pedra
- Navès
- Capolat
- Lladurs
- Vall de Lord
- Solsonès
- Berguedà immediat quan correspongui
- zones adjacents compatibles amb el catàleg

No acceptis una coincidència només perquè el nom coincideix.

Exemple:

`El Jou`

és massa genèric per considerar-lo correcte sense context territorial.

---

## Estratègia de cerca

Per cada estació:

1. Cerca el nom exacte.

2. Si és insuficient, prova variants contextualitzades, per exemple:

   `"Can Pernals" Guixers`
   `"El Jou" La Coma i la Pedra`
   `"Cal Sec" Vall de Lord`
   `"Casa Postils" Navès`

3. Comprova que el resultat és territorialment compatible.

4. Si hi ha múltiples candidats:
   - no triïs arbitràriament;
   - registra'ls a `candidates`;
   - redueix la confiança.

5. Conserva evidència de la consulta utilitzada.

---

Quan existeixi una coincidència prou clara, registra:

- latitude
- longitude

No aproximis manualment coordenades.

No utilitzis:

- centre del municipi;
- centroides;
- coordenades d'una població propera;
- coordenades inferides;
- una masia diferent amb nom semblant.

Si no hi ha evidència suficient:

Confidence

HIGH

nom genèric;
