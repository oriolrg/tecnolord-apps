Determinar amb evidència real quines mètriques meteorològiques ofereix
el dashboard Vall de Lord i com s'han d'interpretar.

Variables objectiu:

- temperatura
- humitat relativa
- pressió atmosfèrica
- pluja / precipitació

Aquesta tasca és només de discovery.

NO modificar:
- BD
- grafanaAdapterService
- snapshotService
- backend funcional
- frontend
- schema

NO avançar H05.

# 1. INSPECCIÓ DEL DASHBOARD

Obtenir la definició/configuració real del dashboard i identificar els
panells meteorològics relacionats amb:

- temperatura
- humitat
- pressió
- precipitació/pluja

Per cada variable determinar:

- títol del panell;
- query exacta;
- mètrica real;
- labels/filtres;
- ús de `$sensor` / `tag4`;
- datasource;
- unitat declarada;
- transformations Grafana;
- expressions post-query, si n'hi ha;
- semàntica del valor.

NO inferir noms de mètriques.

---

# 2. TEMPERATURA

Ja existeix una integració validada per temperatura.

Confirma el contracte actual i registra'l com a baseline.

No modifiquis el comportament existent.

Determina:

- mètrica exacta;
- unitat;
- query;
- timestamp;
- camp canònic actual (`temp_c`) si continua sent correcte.

---

# 3. HUMITAT

Només considerar disponible si Grafana proporciona evidència explícita
que representa humitat relativa.

Determinar:

- mètrica;
- unitat;
- rang esperat;
- transformacions;
- camp canònic MeteoLord existent apropiat.

No assumir que un número 0–100 és necessàriament humitat relativa.

---

# 4. PRESSIÓ

Determinar explícitament:

- mètrica;
- unitat original;
- si és pressió absoluta/local;
- si està corregida a nivell del mar;
- si Grafana aplica alguna conversió;
- camp canònic MeteoLord existent, si n'hi ha.

No assumir `hPa`.

Si no es pot determinar la semàntica:

`SEMANTICS_UNRESOLVED`

---

# 5. PLUJA / PRECIPITACIÓ

Aquesta variable requereix especial rigor.

Determinar si Grafana representa:

- acumulació total;
- acumulació diària;
- acumulació durant la finestra;
- increment entre mostres;
- intensitat;
- rate;
- counter acumulatiu;
- una altra semàntica.

Registrar:

- mètrica;
- unitat;
- query;
- transformacions;
- reset del counter si existeix;
- interpretació exacta.

NO mapar encara aquesta dada a cap camp MeteoLord si la semàntica no
està demostrada.

No confondre:

`mm acumulats`

amb:

`mm/h`

ni amb:

`increment de pluja`.

---

# 6. DISPONIBILITAT PER SENSOR

Utilitza els 29 sensors CURRENT de H01.

Per cada sensor determina la disponibilitat de:

- temperature
- humidity
- pressure
- rain

- `AVAILABLE`
- `NOT_AVAILABLE`
- `UNKNOWN`

No cal descarregar grans volums de dades.

Utilitza la consulta mínima necessària per determinar si existeix una
sèrie vàlida recent.

Evita guardar payloads complets.
