# 10. CONFLICTES

Bloqueja individualment si:

- external_id ja està vinculat a una estació incompatible;
- MLW code ja existeix en una altra estació;
- UUID inesperat;
- nom/codi implica una fusió no demostrada.

No resolguis conflictes automàticament.

Un conflicte individual no ha d'obligar a perdre la resta de l'inventari,
però informa'l clarament.
