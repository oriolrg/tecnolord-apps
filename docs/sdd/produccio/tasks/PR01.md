# PR01 — Inventari READ-ONLY del servidor actual

## Objectiu

Obtenir una fotografia completa i verificable de l'estat actual
del servidor de producció abans de fer backups, restores,
migracions o desplegaments.

Aquesta tasca és EXCLUSIVAMENT READ-ONLY.

Release Candidate de referència:

`321b8a5`

NO executar PR02.
NO desplegar cap beta.
NO modificar producció.

---

## 1. Regla absoluta

Qualsevol operació al servidor productiu ha de ser de lectura.

Prohibit:

- git pull
- git checkout
- git reset
- npm install
- npm ci
- docker compose up
- docker compose down
- docker restart
- docker stop
- docker start
- docker rm
- docker volume rm
- docker system prune
- migracions
- INSERT
- UPDATE
- DELETE
- CREATE
- ALTER
- DROP
- TRUNCATE
- pg_restore
- pg_dump
- modificar Caddy
- modificar fitxers
- crear fitxers al servidor

Mai:

`docker compose down -v`

L'evidència s'ha de guardar exclusivament al repositori/local.

- path
- branch
- HEAD
- tags rellevants
- `git status --short`

Si hi ha canvis locals:
documentar-los i no tocar-los.

## 6. PostgreSQL / PostGIS

Identificar:

- container/service
- PostgreSQL version
- PostGIS version
- databases
- schemas
- extensions
- mida de les bases
- noms dels roles rellevants

No mostrar passwords.

Les consultes han de ser READ ONLY.

Preferentment:

`BEGIN READ ONLY`

amb `statement_timeout` raonable.
